# Revenue metrics (GOIT-Educational-Project)

This project demonstrates an end-to-end SaaS revenue analytics solution built as part of the GoIT Data Analytics program.
The goal was to analyze revenue performance, user behavior, and retention using key SaaS metrics and present insights through interactive dashboards.

## Business Objectives
- Understand revenue dynamics and growth drivers
- Decompose MRR into New, Expansion, Contraction, and Churn components
- Analyze customer lifetime value (LTV), ARPPU, and churn behavior
- Identify high-value user segments by age group and product
- Support data-driven decisions for product, finance, and growth teams

## Key Metrics
- Total Revenue
- Monthly Recurring Revenue (MRR)
- ARPPU (Average Revenue per Paid User)
- Customer Lifetime (LT)
- Customer Lifetime Value (LTV)
- Revenue Churn Rate
- User Retention and Cohorts

## Tools & Technologies
- SQL (PostgreSQL)
- Tableau
- Excel / Google Sheets
- CSV datasets

## Project Structure
- SQL scripts for data preparation and metric calculation
- Cleaned datasets used for visualization
- Tableau dashboards and presentation materials
- Documentation and business insights

## Key Insights
- Revenue growth was primarily driven by Expansion MRR
- Churn MRR increased toward the end of the period, impacting net growth
- ARPPU showed steady growth with a peak in October
- The highest LTV users belong to specific age groups within Game 3
- Retention drops significantly after the first months, highlighting onboarding and engagement risks

## Outcome
Delivered a clear and structured revenue monitoring solution that improves visibility into SaaS performance and supports strategic decision-making.
